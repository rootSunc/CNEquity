# License, sources, and citation

CNEquity source code is [Apache-2.0](https://github.com/rootSunc/CNEquity/blob/main/LICENSE). See [NOTICE](https://github.com/rootSunc/CNEquity/blob/main/NOTICE) for attribution. The package ships the software and its resources. Users collect real market data, financial statements, and disclosures from configured sources and store them locally.

## Upstream data {#source-compliance-matrix}

Check each provider's terms and account permissions before accessing, caching, using commercially, or redistributing data. The software license does not grant market-data redistribution rights.

- [Data and coverage](datasets/catalog.md) lists supported inputs and historical limits.
- The [source policy register](https://github.com/rootSunc/CNEquity/blob/main/sources/SOURCES.yml) records known conditions and items awaiting review. Run `cne sources policy` to see what your installation records. An `unknown` or `review_required` status calls for verification.
- The [offline sample](getting-started/quickstart.md#offline-sample) generates synthetic data for demonstration and software checks.

## Citation and feedback {#citation}

Cite the software using [CITATION.cff](https://github.com/rootSunc/CNEquity/blob/main/CITATION.cff) and give the version you used. For research results, also record data sources, coverage, and the data revisions used.

For ordinary questions, see [project support](https://github.com/rootSunc/CNEquity/blob/main/.github/SUPPORT.md). Report security issues through the [security policy](https://github.com/rootSunc/CNEquity/blob/main/SECURITY.md).
