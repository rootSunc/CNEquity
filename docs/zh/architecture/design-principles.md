# 设计原则

## 数据质量优先

明确来源、单位、日期语义与覆盖边界。未知和缺失应显式展示；不能用空表、默认值或当前状态冒充已经核实的历史事实。

## 用户掌握数据

数据保存在本地开放格式中，可用常用分析工具读取。采集范围、可选来源与调度由用户配置，项目不承诺上游永久可用。

## 研究口径可检查

原始价格与复权因子分别保存。历史股票池、PIT 与复权有独立证据要求。示例与离线 sample 用于验证使用方法，不代表研究覆盖已经通过。

## 纠错可追溯

数据纠错发布新版本。长期复现需要保存数据依赖、查询参数和软件版本；仅保存最大日期或水位不足以固定研究输入。

## 可使用、可恢复

优先提供清晰的安装、运行、诊断与恢复入口。兼容性变化通过更新日志和迁移说明告知用户。

CNEquity 与 USEquity 共享的 Error / Warning / Caveat 边界与 Quality Tier (`A/B/C`) 规范见[共享数据质量契约](data-quality-contract.md)。当前功能和限制见[产品方向](overview.md)、[数据目录](../datasets/catalog.md)与[升级说明](../getting-started/installation.md#升级与兼容性)。
