# 许可、来源与引用

CNEquity 的代码采用 [Apache-2.0](https://github.com/rootSunc/CNEquity/blob/main/LICENSE)，归属与声明见 [NOTICE](https://github.com/rootSunc/CNEquity/blob/main/NOTICE)。安装包包含程序与资源。真实行情、财报和公告由用户从已配置的来源采集，存放在本地。

## 上游数据 {#source-compliance-matrix}

获取、缓存、商业使用或再分发前，查看相应数据提供方的条款和账号权限。软件许可不授予市场数据的再分发权限。

- [数据与覆盖](datasets/catalog.md)说明软件接入的来源和历史限制。
- [来源合规登记表](https://github.com/rootSunc/CNEquity/blob/main/sources/SOURCES.yml)记录已知条件和待确认事项。用 `cne sources policy` 查看当前安装的登记结果。`unknown` 或 `review_required` 表示仍需核实。
- [离线样例](getting-started/quickstart.md#offline-sample)生成合成数据，可用于演示和验证程序。

## 引用与反馈 {#citation}

引用软件时使用仓库的 [CITATION.cff](https://github.com/rootSunc/CNEquity/blob/main/CITATION.cff)，并注明实际使用的版本。研究结论可以另外记录数据来源、覆盖区间和使用的数据修订。

一般问题使用[项目支持入口](https://github.com/rootSunc/CNEquity/blob/main/.github/SUPPORT.md)。安全问题通过[安全策略](https://github.com/rootSunc/CNEquity/blob/main/SECURITY.md)报告。
